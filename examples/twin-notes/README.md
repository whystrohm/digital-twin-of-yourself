# Sample notes for the demo twin

Made up. Maya is a fictional operations lead at a fictional company. These are the notes the twin runs on until you point it at your own.

One note per file. The first lines say what the note is and which of the five areas it belongs to:

```markdown
---
description: We ship Tuesday to Thursday. Never on a Friday.
area: decisions
---

Maya, 2026-03-04: We ship Tuesday to Thursday. Never on a Friday.

**Why:** A Friday problem sits all weekend with nobody to fix it.
```

`area` is one of `decisions`, `taste`, `voice`, `work`, `limits`. A dated line in the body sets when the note was first true. A `**Why:**` line is shown with the note.
