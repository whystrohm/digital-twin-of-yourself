# What is bundled here

- `Archivo-VF.ttf`: Archivo, copyright The Archivo Project Authors. SIL Open Font License 1.1, see `OFL.txt`. Unmodified.
- `IBMPlexMono-Regular.ttf`: IBM Plex Mono, copyright IBM Corp., with Reserved Font Name "Plex". SIL Open Font License 1.1, see `OFL.txt`. Unmodified.
- `head.bin`, `head.json`: the demo head. The face is generated. It is not a real person.
- `head/build.py` downloads the YuNet face detector from the OpenCV Zoo the first time it checks or builds a photo. It is not stored in this repo.
